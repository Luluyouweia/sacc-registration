# 关于前端开发

## 前端——HTML,CSS,JavaScript的交响乐

**HTML**，前端大楼的基础建筑结构，客户端的框架，是基于HTML技术的。

**CSS**，前端大楼的设计蓝图，大楼的一砖一瓦，由CSS包装，此后，大楼变得色彩鲜艳，它奠定了大楼的内外样式。

**JS**，前端大楼的科技基础，大楼使得居民有了交互体验感，而非HTML,CSS机械式的静止态。整个网页活了起来，用户的一举一动，可以被捕捉，从而做出响应。

当HTML奠定前端之基，CSS赋予前端艳丽之色，JavaScript赋予数据以灵魂并操作DOM灵动变化，前端的魅力便随之绽放。

## 前端随时代不断变化

前端，不至于网页，H5类小程序随互联网发展而进步。前端内容打包为桌面软件，手机应用，逐渐统一为各大设备平台开发的优秀语言组合。WebGL甚至WebGPU让前端步足3D场景，Three.js,Babylon的开源仓库正愈发完善。Node.js让JavaScript的语法也走向后端方向。
