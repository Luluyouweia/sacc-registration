## \*JavaScript与DOM事件交互

使得网页灵活地动起来，通过JS操作DOM肯定是是不可缺少的环节啊（＾ｖ＾） ，对吧！

## 一、核心定义：DOM 是什么？

* **DOM（Document Object Model，文档对象模型）**：浏览器将 HTML 解析成的一棵**树形结构**（节点树），使得 JavaScript 可以动态访问、修改文档的内容、结构和样式。

* **本质**：JS 操作 DOM 的 API 是**同步、阻塞**的，且运行在浏览器主线程。

***

## 二、DOM 树与节点类型

* **`document`**：树的根节点（入口）。

* **节点类型（`nodeType`）**：

  * 元素节点（`<div>`）

  * 文本节点（实际文字）

  * 文档节点（`document`）

* **重要关系属性**：

  * `parentNode` / `parentElement`（父节点）

  * `childNodes`（含文本节点） / `children`（仅元素节点，**推荐**）

  * `firstElementChild` / `lastElementChild`（首尾元素）

  * `nextElementSibling` / `previousElementSibling`（兄弟元素）

***

## 三、获取 DOM 元素（选择器 API）

| 方法                                         | 返回类型                           | 动态性（Live/Static） | 适用场景               |
| :----------------------------------------- | :----------------------------- | :--------------- | :----------------- |
| `document.getElementById('id')`            | 单个元素                           | Live（实时更新）       | **最快**，精确获取唯一 ID   |
| `document.getElementsByClassName('class')` | **HTMLCollection**（类数组）        | **Live**         | 旧代码常用，操作时注意长度变化    |
| `document.getElementsByTagName('div')`     | **HTMLCollection**（类数组）        | **Live**         | 同上                 |
| `document.querySelector('.class')`         | 单个元素（**首个匹配**）                 | Static（静态快照）     | **最通用**，支持 CSS 选择器 |
| `document.querySelectorAll('.class')`      | **NodeList**（类数组，可用 `forEach`） | **Static**（静态快照） | **推荐首选**，灵活性最高     |

### ⚠️ 关键坑：`querySelectorAll` 返回的 NodeList 是**静态的**，不会随 DOM 更新自动变化；而 `getElementsBy...` 是 **Live 集合**，会实时反映 DOM 变化（循环时尤其危险，容易死循环）。

***

## 四、DOM 增删改查（CRUD）

### 1. 创建元素

* `document.createElement('div')`（创建元素节点）

* `document.createTextNode('文本')`（创建文本节点，较少直接使用，多用 `textContent`）

### 2. 插入子节点

| 方法                                | 插入位置             | 现代替代（推荐）                                                                                |
| :-------------------------------- | :--------------- | :-------------------------------------------------------------------------------------- |
| `parent.appendChild(child)`       | 作为**最后一个**子节点    | `parent.append(child)`（可追加多个或字符串）                                                       |
| `parent.insertBefore(child, ref)` | 在 `ref` 节点**之前** | `parent.prepend(child)`（作为第一个）`ref.before(child)`（在 ref 之前）`ref.after(child)`（在 ref 之后） |

### 3. 删除与替换

* `parent.removeChild(child)`（传统） → **现代直接** **`child.remove()`**（更简洁）

* `parent.replaceChild(new, old)` → **现代用** **`old.replaceWith(new)`**

### 4. 克隆节点

* `node.cloneNode(true)`（**深克隆**，复制内部所有子节点） / `cloneNode(false)`（仅复制自身，不克隆子元素）。**注意：克隆不会复制事件监听器**。

***

## 五、修改内容、属性与样式

### 1. 内容操作（核心区别）

| 属性                    | 行为                   | XSS 风险          | 场景               |
| :-------------------- | :------------------- | :-------------- | :--------------- |
| `element.textContent` | 纯文本，**自动转义 HTML 标签** | **安全**          | 99% 场景首选（性能更好）   |
| `element.innerHTML`   | 解析并渲染 HTML 字符串       | **高危**（用户输入不可用） | 仅在插入完全可信的静态模板时使用 |
| `element.innerText`   | 近似文本（触发回流，慢），忽略隐藏元素  | 安全              | 特殊场景取用户可见文字      |

### 2. 属性操作

* **标准属性**：`img.src = 'a.jpg'`、`input.value = 'text'`（直接点语法）

* **自定义/任意属性**：`element.getAttribute('data-id')` / `element.setAttribute('data-id', '123')`

* **`data-*`** **自定义属性（推荐）**：通过 `element.dataset.id` 读写（自动驼峰转换，如 `data-user-id` → `dataset.userId`）

### 3. 样式操作（CSS 类优先）

* **行内样式（不推荐）**：`element.style.color = 'red'`（仅用于动态计算或紧急覆盖）。

* **类名操作（最佳实践）**：使用 `classList` API（完美兼容）：

  * `element.classList.add('active')`

  * `element.classList.remove('hidden')`

  * `element.classList.toggle('open')`

  * `element.classList.contains('selected')`（返回布尔值）

## 六、事件处理（核心交互）

### 1. 绑定方式进化史

| 方式                              | 示例                                      | 缺点                                                  |
| :------------------------------ | :-------------------------------------- | :-------------------------------------------------- |
| HTML 内联（`onclick`）              | `<div onclick="fn()">`                  | 耦合 HTML/JS，维护难                                      |
| DOM 0 级（`on` 属性）                | `element.onclick = fn`                  | 只能绑定一个，后绑覆盖先绑                                       |
| **DOM 2 级（`addEventListener`）** | `element.addEventListener('click', fn)` | **标准方法**，可绑定多个，解绑用 `removeEventListener`（需传入相同函数引用） |

### 2. 事件流与传播机制（面试高频）

1. **捕获阶段**（从 `window` → 目标元素的父级，极少拦截，`addEventListener` 第三个参数传 `true` 可监听）
2. **目标阶段**（触发目标元素）
3. **冒泡阶段**（从目标 → `window`，**默认监听此阶段**）


### 3. 事件对象（`event`）常用 API

```javascript
element.addEventListener('click', function(e) {
  e.preventDefault();      // 阻止默认行为（如 <a> 跳转、表单提交）
  e.stopPropagation();     // 阻止事件冒泡（注意：滥用会导致上层监听失效）
  e.target;                // 实际触发事件的元素（点击穿透目标）
  e.currentTarget;         // 绑定监听器的元素（this 指向它）
});
```
