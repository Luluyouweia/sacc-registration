# 2.HTML表单

*AI工具 Deepseek R1参与生成*

## 一、核心定义与作用

* **`<form>`** 是 HTML 中用于**收集用户输入**并提交到服务器的核心交互元素。

* 它定义了数据提交的**目标地址（action）** 和**提交方式（method）**，是用户与后端交互的桥梁。

***

## 二、`<form>` 标签关键属性

| 属性             | 说明                                         | 常用值/示例                                                                                              |
| :------------- | :----------------------------------------- | :-------------------------------------------------------------------------------------------------- |
| `action`       | 提交数据的服务器端 URL（接口地址）                        | `action="/api/login"`  若省略，则提交到当前页面 URL                                                             |
| `method`       | HTTP 请求方法                                  | **`get`**（默认，数据附在 URL 后，有长度限制，不安全）**`post`**（数据在请求体中，无长度限制，较安全，**推荐用于提交/修改数据**）                     |
| `enctype`      | 数据编码类型（**仅在** **`method="post"`** **时生效**） | `application/x-www-form-urlencoded`（默认）`multipart/form-data`（**必选**：表单含文件上传时）`text/plain`（调试用，极少使用） |
| `target`       | 提交后响应结果的显示位置                               | `_self`（当前窗口，默认）`_blank`（新窗口/标签页）`_parent` / `_top`（框架页面用）                                          |
| `autocomplete` | 浏览器是否自动填充                                  | `on`（默认） / `off`（敏感信息如密码建议关掉）                                                                       |
| `novalidate`   | 禁用浏览器原生验证（常用于自定义验证逻辑）                      | 布尔属性，直接写 `novalidate`                                                                               |

***

## 三、常用表单控件详解

### 1. `<input>` 核心控件（通过 `type` 切换形态）

| `type` 值   | 用途                                                 | 特有属性                                                |
| :--------- | :------------------------------------------------- | :-------------------------------------------------- |
| `text`     | 单行文本（默认）                                           | `placeholder`、`maxlength`                           |
| `password` | 密码输入（自动掩码）                                         | `autocomplete="off"`（推荐）                            |
| `email`    | 邮箱地址（移动端调出 @ 键盘）                                   | 自带基础格式验证                                            |
| `number`   | 数字输入（调出数字键盘）                                       | `min`、`max`、`step`                                  |
| `tel`      | 电话号码（移动端调出数字键盘）                                    | `pattern`（正则验证）                                     |
| `url`      | 网址链接                                               | 自带基础 URL 格式验证                                       |
| `search`   | 搜索框（部分浏览器带清除按钮）                                    | `placeholder`                                       |
| `file`     | 文件上传（**必须配合** **`enctype="multipart/form-data"`**） | `accept`（限制文件类型，如 `accept="image/*"`）`multiple`（多选） |
| `checkbox` | 复选框（多选）                                            | `checked`（默认选中）同一组需同名 `name`                        |
| `radio`    | 单选框（互斥）                                            | 同一组必须**同名** **`name`** 才能互斥，`value` 区分选项            |
| `hidden`   | 隐藏字段（传递固定参数，用户不可见）                                 | `value` 预设值                                         |
| `submit`   | 提交按钮（点击触发表单提交）                                     | `value` 定义按钮文字                                      |
| `reset`    | 重置按钮（恢复表单默认值，**不常用**）                              | `value`                                             |
| `button`   | 普通按钮（无默认行为，需 JS 绑定）                                | `value`                                             |

### 2. `<textarea>` 多行文本域

* 用 `rows` 和 `cols` 控制初始尺寸（CSS 优先）。

* `placeholder` 提示占位文字。

* **注意**：标签内不要换行（换行会被当作文本内容）。

### 3. `<select>` + `<option>` 下拉列表

```html
<select name="city" required>
  <option value="">请选择</option>   <!-- value 为空则提交空值 -->
  <option value="bj">北京</option>
  <option value="sh" selected>上海</option> <!-- selected 默认选中 -->
</select>
```
