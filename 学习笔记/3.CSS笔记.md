## 一、核心定义与作用

* **CSS（Cascading Style Sheets，层叠样式表）**：用于控制 HTML 元素的呈现与布局，实现**内容与样式分离**，提高代码可维护性与复用性。

* 核心机制：**层叠性**（样式冲突时按规则覆盖）、**继承性**（父级样式传递子级）、**优先级**（权重决定最终生效规则）。

---

## 二、CSS 的三种使用方式及优先级（层叠规则）

| 插入方式                | 语法示例                                       | 优先级权重           | 适用场景              |
| :------------------ | :----------------------------------------- | :-------------- | :---------------- |
| **行内样式（Inline）**    | `<div style="color: red;">`                | **最高**（权重 1000） | 紧急覆盖、JS 动态控制      |
| **内部样式表（Internal）** | `<style> div { color: red; } </style>`     | 中（按选择器权重）       | 单页独有样式、快速测试       |
| **外部样式表（External）** | `<link rel="stylesheet" href="style.css">` | 中（按选择器权重）       | **生产环境推荐**（复用、缓存） |

### ⚠️ 终极权重排序（由高到低）

1. **`!important`**（破坏级，慎用） > 2. **行内样式** > 3. **ID 选择器** > 4. **类/伪类/属性选择器** > 5. **元素/伪元素选择器** > 6. **通配符（`*`）**

> 同权重下，**后声明（代码位置靠后）** 的样式生效。

***

## 三、核心选择器全览

### 1. 基础选择器

| 类型       | 语法       | 示例                               | 权重  |
| :------- | :------- | :------------------------------- | :-- |
| 通配符      | `*`      | `* { margin: 0; }`               | 0   |
| 元素/标签    | `div`    | `p { color: blue; }`             | 1   |
| 类（Class） | `.class` | `.nav { display: flex; }`        | 10  |
| ID       | `#id`    | `#header { height: 60px; }`      | 100 |
| 属性       | `[attr]` | `[type="text"] { border: 1px; }` | 10  |

### 2. 组合选择器（层级关系）

| 组合        | 语法      | 说明              | 示例          |
| :-------- | :------ | :-------------- | :---------- |
| 后代（空格）    | `A B`   | A 内部所有 B（不限层级）  | `.list li`  |
| 子元素（`>`）  | `A > B` | A 的直接子级 B（仅下一层） | `.nav > li` |
| 相邻兄弟（`+`） | `A + B` | A 后面紧邻的第一个 B    | `h1 + p`    |
| 通用兄弟（`~`） | `A ~ B` | A 后面所有同级的 B     | `h2 ~ p`    |

### 3. 伪类（状态）与伪元素（片段）

* **伪类（`: `）**：针对特定状态（`:hover`、`:focus`、`:nth-child(n)`、`:last-child`、`:not()`）。

* **伪元素（`::`）**：创建虚拟元素（`::before`、`::after`、`::first-line`）。

> *注意：伪元素在 CSS3 后用双冒号区分，但单冒号也兼容。*

## 四、盒模型

### 1. 组成部分（由内到外）

**Content（内容） → Padding（内边距） → Border（边框） → Margin（外边距）**

### 2. 两种盒模型（`box-sizing`）

| 属性值                   | 计算规则                                         | 适用场景            |
| :-------------------- | :------------------------------------------- | :-------------- |
| `content-box`（**默认**） | `width` 只包含内容区，总宽 = width + padding + border | 传统模式，计算复杂       |
| `border-box`（**推荐**）  | `width` 包含内容 + padding + border，总宽直接 = width | **布局最友好**，移动端必备 |

```css
/* 全局重置为 border-box 是业界最佳实践 */
* { box-sizing: border-box; }
```
