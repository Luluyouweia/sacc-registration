# HTML 知识总结

*AI工具 Deepseek R1参与生成*

HTML（HyperText Markup Language，超文本标记语言）是构建网页的基础语言，用于描述网页的结构和内容。浏览器解析 HTML 文件，将其渲染为可视化的页面。

***

## 文档基本结构

每个 HTML 文件都遵循以下骨架：

```
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
</head>
<body>
  <!-- 页面可见内容 -->
</body>
</html>
```

* `<!DOCTYPE html>`：声明文档类型为 HTML5。

* `<html>`：根元素，`lang` 属性声明页面语言。

* `<head>`：存放元数据（字符编码、视口设置、标题、引入样式/脚本）。

* `<body>`：所有用户可见的内容。

***

## 核心概念

### 标签（Tag）

* 用尖括号包裹，如 `<p>`、`<div>`。

* 多数标签成对出现（开始标签 + 结束标签），如 `<p>文字</p>`。

* 部分标签自闭合，如 `<img src="..." alt="...">`、`<br>`、`<hr>`。

### 属性（Attribute）

* 写在开始标签内，格式为 `属性名="属性值"`。

* 用于提供额外信息，如 `<a href="https://example.com">链接</a>` 中的 `href`。

### 语义化

* 使用具有明确含义的标签（如 `<header>`、`<nav>`、`<main>`、`<article>`）描述内容结构，有利于搜索引擎优化（SEO）和屏幕阅读器等辅助工具。

***

## 常用标签分类

### 文档结构（语义标签）

* `<header>` – 页面或区域的头部。

* `<nav>` – 导航链接区域。

* `<main>` – 页面主内容（每页仅一个）。

* `<article>` – 独立完整的内容块（如博客文章、新闻）。

* `<section>` – 内容分区，通常包含标题。

* `<aside>` – 侧边栏或附属信息。

* `<footer>` – 页面或区域的底部。

* `<figure>` + `<figcaption>` – 插图及其标题。

### 文本与排版

* 标题：`<h1>` 到 `<h6>`（按层级使用，不可跳级）。

* 段落：`<p>`。

* 换行：`<br>`。

* 分割线：`<hr>`。

* 强调：`<strong>`（加粗，表示重要性）、`<em>`（斜体，表示语气强调）。

* 引用：`<blockquote>`（块级）、`<q>`（行内）。

* 代码：`<code>`（行内代码）、`<pre>`（预格式化，保留空格换行）。

* 其他：`<abbr>`（缩写）、`<time>`（时间）、`<mark>`（高亮）。

### 链接与媒体

* 超链接：`<a href="URL">`，可加 `target="_blank"` 在新窗口打开，`download` 属性实现下载。

* 图片：`<img src="路径" alt="替代文本">`（`alt` 必填，装饰图片可写空字符串）。

* 响应式图片：`<picture>` 内嵌多个 `<source>`。

* 视频：`<video src="..." controls>`（可加 `autoplay`、`loop`、`poster`）。

* 音频：`<audio src="..." controls>`。

* 内嵌页面：`<iframe src="..." sandbox>`（注意安全限制）。

### 列表

* 无序列表：`<ul>` + `<li>`（用于导航、菜单）。

* 有序列表：`<ol>` + `<li>`（用于步骤、排名）。

* 定义列表：`<dl>` + `<dt>`（术语）+ `<dd>`（描述）。

> 嵌套列表时，子 `<ul>`/`<ol>` 必须放在 `<li>` 内部。

### 表格

```html-block
    <table>
      <caption>表格标题</caption>
      <thead>
        <tr><th>表头1</th><th>表头2</th></tr>
      </thead>
      <tbody>
        <tr><td>数据1</td><td>数据2</td></tr>
      </tbody>
      <tfoot>
        <tr><td colspan="2">汇总</td></tr>
      </tfoot>
    </table>
```

* 合并单元格：`colspan`（跨列）、`rowspan`（跨行）。

* 推荐使用 CSS 控制边框，弃用 `border`、`cellpadding` 等属性。

### 表单

* 容器：`<form action="提交地址" method="get|post" enctype="...">`

* 输入控件：`<input type="类型" name="字段名" ...>`

  * 常见 `type`：`text`、`password`、`email`、`number`、`file`、`checkbox`、`radio`、`submit`、`button`、`hidden`、`date`、`color`、`range` 等。

* 多行文本：`<textarea name="..." rows="..." cols="...">`

* 下拉列表：`<select name="...">` + `<option value="...">`

* 按钮：`<button type="submit|reset|button">`（在表单内默认 `submit`）。

* 标签：`<label for="控件id">` 点击文字聚焦控件（可访问性必备）。

* 分组：`<fieldset>` + `<legend>`。

> **重要规则**：所有要提交的数据控件必须有 `name` 属性。文件上传必须 `method="post"` 且 `enctype="multipart/form-data"`。单选框（radio）实现互斥需使用相同的 `name`。

### 容器标签（无语义）

* `<div>` – 块级容器，用于页面布局。

* `<span>` – 行内容器，用于包裹文本片段。

***

## 块级元素 vs 行内元素

| 特性           | 块级元素                                           | 行内元素                                        |
| ------------ | ---------------------------------------------- | ------------------------------------------- |
| 换行           | 独占一行                                           | 不换行，与其他行内共享                                 |
| 宽高设置         | 有效                                             | 无效（由内容撑开）                                   |
| 上下边距（margin） | 生效                                             | 上下无效，左右有效                                   |
| 典型标签         | `<div>`、`<p>`、`<h1>`、`<ul>`、`<table>`、`<form>` | `<span>`、`<a>`、`<strong>`、`<img>`、`<input>` |

可通过 CSS `display` 属性相互转换（如 `display: inline-block`）。

***

## 头部 `<head>` 关键元素

* `<meta charset="UTF-8">` – 字符编码（必须放在 `title` 之前）。

* `<meta name="viewport" content="width=device-width, initial-scale=1.0">` – 移动端适配。

* `<title>` – 页面标题，显示在浏览器标签栏，SEO 核心。

* `<link rel="stylesheet" href="...">` – 引入外部 CSS。

* `<link rel="icon" href="...">` – 网站图标。

* `<script src="..." defer>` – 引入外部 JS，建议加 `defer` 防阻塞渲染。

* `<style>` – 内部 CSS。

* `<base href="...">` – 全局基准 URL（慎用）。

## 路径类型

* **绝对路径**：`https://example.com/images/photo.jpg`

* **根相对路径**：`/images/photo.jpg`（从网站根目录开始）

* **同级相对**：`photo.jpg`

* **上级相对**：`../photo.jpg`

* **锚点跳转**：`#section-id`（对应页面内 `id="section-id"` 的元素）

## HTML5 新增特性

* **语义化标签**：`<header>`、`<nav>`、`<main>`、`<article>`、`<section>`、`<aside>`、`<footer>`。

* **表单增强**：新增 `type`（`email`、`url`、`number`、`range`、`date`、`color`、`search`、`tel`）及验证属性（`required`、`pattern`、`min`/`max`、`minlength`/`maxlength`）。

* **多媒体**：`<audio>`、`<video>` 原生支持。

* **图形**：`<canvas>` 和 SVG。

* **客户端存储**：`localStorage`、`sessionStorage`。

* **拖放 API**。

* **地理位置 API**。
